# IMAXER
---  
## 1. サービス概要（※最後に書いてOK）

「IMAXER」は、観たい作品をIMAXで上映している映画館を一括検索できるサービスです。
複数の映画館サイトを一つずつ確認することなく、現在IMAX上映中の映画館を簡単に探せます。

---
## 2. このアイデアはどこから生まれたか

### 2-1. きっかけとなった体験・感情

皆さんは映画館で映画を観ますか？
私はしばしば映画館に足を運んで観に行きます。
私は迫力を求めているので「IMAX」の映画しか観に行きません。
そもそもIMAXをご存じでない方もいらっしゃると思うので簡単にいうと、
追加料金を支払うことで、通常より大型のスクリーンで高音質な映画を楽しめる上映方式です。
ただ、IMAXを導入している映画館は限られており、1館あたりのIMAXスクリーン数も少ないです。
そのためIMAX映画が複数被っている時期など、自分が観たいIMAX映画の上映回数が少なかったりすぐに上映終了することがあります。
そうしたときに自分の観たい映画のIMAXを探すには、いちいちそれぞれの映画館の公式サイトを検索し、自分が観たい映画のIMAXがまだ上映しているかどうか調べる必要があります。
そのような手順が非常に面倒で、一回検索するだけでどこでまだ上映しているか確認できるようなサイトやアプリがあったらいいなと感じました。

---
### 2-2. なぜそれが「気になった」のか

私は映画館で観る場合はどうせなら迫力のあるアクション映画などを観たいと思っています。
なので基本的にIMAXでしか観ませんし、IMAXがない映画やIMAXが終了している映画を観たいと思わないのです。
気になっている映画であったとしてもIMAXが終了していた場合は観に行きません。
どうせ後でアマプラやネトフリなどで配信されるからそれを観ればいいかと思ってしまうのです。
映画館で観るのであればその価値を最大限に高めたIMAXで観たいのです。

## 3. 課題の整理

### 3-1. 表に観えている困りごと

自分が観たい映画のIMAXが今どの映画館で上映しているのか、一覧で観ることができないことです。
  
---
### 3-2. 本当に解決したい課題は何か

「観たい映画のIMAXの上映情報が一覧化されていない」
- IMAXを導入している映画館の公式サイトを一つずつ確認しなければならないからです。
- 映画館ごとに上映終了時期や公開映画が異なるため、複数の映画館を確認する必要があり、探す手間がかかります。
- 映画を観るたびに繰り返していると探すこと自体が面倒になり、まだ上映している映画館があっても探すことを諦めてしまいます。

## 7. このアプリで実現すること

### MVPで作る機能

・都内の2～3の映画館のIMAX上映情報の検索機能
・対象の映画館のサイトからIMAXの上映情報を取得し・更新する機能
・映画タイトルの入力で現在IMAX上映をしている映画館の一覧を表示

### 本リリースで作る機能

・GPS情報を追加し、最寄りのIMAX映画館を表示する。
・関東エリアのIMAX映画館情報の追加する。
・ユーザー登録・ログイン・ログアウト機能を追加する。
・マイページにお気に入りの映画館を登録できるようにする。

## 8. このアプリの懸念点とその対策

### 懸念点①

- 何が問題になりそうか：映画館の上映情報は各映画館の公式サイトから自動取得する必要があり、映画館によっては利用規約違反となることです。
- なぜそう思うか：映画館の公式サイトによって利用規約やrobots.txtの内容が異なり、自動取得を許可していない可能性があります。
- そのために考えている対策：利用規約やrobots.txtを確認し、自動取得に問題がないと判断できる映画館を対象とする。
　　　　　　　　　　　　　　また、MVPでは対象とする映画館を限定する。

---
### 10-2. 技術選定の比較検討


| 候補               | 採用/不採用  | 理由                                                   |
| ---------------- | ------- | ---------------------------------------------------- |
| React            | 不採用     | MVP時点では不要。卒業制作の着手が遅れているため本リリース時に利用を検討する。             |
| Render           | 採用      | 一度ミニアプリをデプロイした際にRenderを使用した経験があるためキャッチアップコストの低減。                 |
| Sidekiq          | 不採用     | バックグラウンドジョブ用のGemだが、MVP時点では複雑なバックグラウンド処理は実装しないので不採用。  |
| Render Cron Job  | 採用      | 映画の上映情報を毎日夜中に一度取得するためのバックグラウンド処理を実装するため。             |
| Nokogiri         | 採用      | 映画サイトのHTML情報を解析して取得するためのライブラリ。                       |
| Neon             | 採用      | ミニアプリ作成時に利用した経験があるためキャッチアップコストの低減。                                |

- 今回チャレンジしたい点
→Render Cron Jobを使用して上映情報の定期取得を実装する。
- 不安な点
→映画情報を実際に取得することができるのかどうか。
